# Shaq’s Big Shot

An unofficial browser basketball game concept by Rich Made It. DJ Diesel on the decks, cartoon Charles Barkley in the paint, and a score for friends to beat.

Play: https://richmadeit.github.io/richmadeit-submissions/

Swipe up anywhere on the court and release to shoot. The court fits small phone screens; the page stays still during a shot gesture and scrolls normally outside the court. Tap the large MUSIC button beside the court to pause or switch tracks. The game clock waits while the music panel is open.

This branch contains only the game’s public website. GitHub Pages publishes from the `shaqs-big-shot` branch and `/ (root)` folder.

No Shaq endorsement implied. Music plays from official external sources and is not downloaded or rehosted.
