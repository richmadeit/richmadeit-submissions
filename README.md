# Shaq’s Big Shot

An unofficial browser basketball game concept by Rich Made It. DJ Diesel on the decks, cartoon Charles Barkley in the paint, and a score for friends to beat.

This branch contains only the game’s public website. Publish GitHub Pages from the `shaqs-big-shot` branch and `/ (root)` folder.

No Shaq endorsement implied. The music plays from official external sources and is not downloaded or rehosted.
